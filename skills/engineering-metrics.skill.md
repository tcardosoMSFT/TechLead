# Skill: Engineering Metrics

## When to use

Use this skill when a tech lead wants to collect or interpret GitHub Copilot usage, pull request volume, repository activity, or delivery flow metrics.

## Instructions

1. Confirm the organization, repositories, and date range.
2. Prefer aggregated team or repository metrics.
3. Use GitHub CLI and GitHub APIs for collection.
4. Export raw data to ignored local output folders.
5. Summarize trends, risks, and recommended enablement actions.

## Starter prompt

```text
Collect GitHub engineering metrics for this organization and repository set. Include pull requests created per month, pull requests merged per month, and Copilot usage metrics where API permissions allow. Produce an aggregated tech lead summary.
```
