# Skill: Engineering Standards

## When to use

Use this skill when creating, checking, or improving engineering standards, architecture guidance, repository instructions, or implementation playbooks.

## Instructions

1. Identify the standard or architecture decision being applied.
2. Check whether code and documentation follow the guidance.
3. Suggest practical changes that can be enforced through review, tests, or automation.
4. Convert recurring issues into reusable instructions.

## Starter prompt

```text
Assess this repository against our engineering standards. Focus on API consistency, testing, observability, security, reliability, and architecture boundaries.
```
