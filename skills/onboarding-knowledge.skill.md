# Skill: Onboarding and Knowledge Transfer

## When to use

Use this skill when onboarding new engineers, explaining legacy code, documenting flows, or creating first-contribution tasks.

## Instructions

1. Explain the repository at a practical level.
2. Identify key modules, commands, tests, and runtime flows.
3. Create a short learning path.
4. Suggest safe first tasks.
5. Keep sensitive information out of generated material.

## Starter prompt

```text
Create an onboarding guide for a new engineer joining this repository. Include the main architecture, important files, local commands, test strategy, and a safe first contribution.
```
