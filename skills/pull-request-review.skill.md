# Skill: Pull Request Review

## When to use

Use this skill when reviewing a pull request, preparing a review checklist, or coaching reviewers.

## Instructions

1. Summarize the PR intent.
2. Identify risky files and behavior changes.
3. Check tests, reliability, security, and observability.
4. Provide concise review comments only for material issues.
5. Suggest reusable guidance when feedback repeats.

## Starter prompt

```text
Review this PR as a tech lead. Focus on material correctness, security, reliability, maintainability, and test coverage issues. Avoid style-only feedback.
```
